# Best Choice Prototype

Interactive mobile prototype recreated from the **UI** page of the Best Choice Figma project.

## Demo flow

- Search for a laptop
- Pick filters and sort product results
- Select 2–3 products for comparison
- Compare detailed specifications
- Open the price-history chart and change its time range

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

Designed for a 402 × 874 mobile viewport and responsive desktop presentation.
